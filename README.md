# Civilis ChatGPT App — version facile iPhone

Cette version n'a que 2 fichiers nécessaires à uploader sur GitHub :

- `package.json`
- `server.js`

Le HTML de l'interface Civilis est directement intégré dans `server.js`, donc aucun dossier `public` n'est nécessaire.

## Render
Build command:
`npm install`

Start command:
`npm start`

L'endpoint MCP sera:
`https://VOTRE-SERVICE.onrender.com/mcp`
